# Conferences

Research notes the `cfp-writer` agent writes after studying a conference: the CFP form's fields and limits, the tracks and formats, and the patterns in what the conference accepted in its last one or two editions, with example titles. One file per conference, named by slug, dated at the top so a later run knows how old it is.

The agent refreshes these every run; they are a starting point, not a substitute for looking again.
